# May Harmony Find You - Quick Color Reference

## Approved Colors ✅

### Primary Colors
```
Dark Blue:  #04405F
Brand Blue: #3483EB
Light Cyan: #8AE1F0
Light BG:   #F0FCFD
```

### Accent Color
```
Orange: #f5771d
```

## Quick Usage

### Buttons
```css
/* Primary */
background-color: #3483EB;
/* Accent */
background-color: #f5771d;
```

### Text
```css
/* Headings */
color: #04405F;
/* Body */
color: #333333;
```

### Backgrounds
```css
/* Navigation/Footer */
background-color: #04405F;
/* Sections */
background-color: #F0FCFD;
```

## Tailwind Classes

```html
<!-- Dark blue background -->
<div class="bg-brand-dark text-white">

<!-- Brand blue button -->
<button class="bg-brand-blue text-white px-4 py-2 rounded">

<!-- Orange accent -->
<span class="text-brand-orange">Special</span>

<!-- Light background -->
<div class="bg-brand-bg-light">
```

## Gradients

```css
/* Hero Section */
background: linear-gradient(135deg, #3483EB 0%, #1DC5E1 50%, #8AE1F0 100%);

/* Promotional */
background: linear-gradient(135deg, #f5771d 0%, #e65c00 100%);
```
